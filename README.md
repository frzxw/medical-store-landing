# Medical Store Landing

One-page site for a medical supply store: who they are, what they sell and service, where to buy online, and how to reach
them.

## Sections

- **About**: the store and its years in business
- **Services**: product categories and after-sales service
- **Marketplace**: links to the store's marketplace listings
- **Contact**: address with a map link, phone, email, social links and WhatsApp

The navigation collapses into a slide-over sheet on mobile.

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS, shadcn/ui primitives (Radix Dialog, Slot) and Font Awesome and
Lucide icons. The page is a single component in `components/landing-page.tsx`.

## Run it locally

```sh
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```
